# Vinisha Raj — Portfolio Website

A responsive portfolio starter built with HTML, CSS and vanilla JavaScript. No frameworks or build tools are required.

## Run locally
1. Extract this folder.
2. Open `index.html` in your browser.

## Personalize before publishing
- Replace the `https://github.com/` placeholder links in `index.html` with your real GitHub profile and repository URLs.
- Update project titles/descriptions so they describe work you have actually completed.
- Check the email address and replace it if needed.
- Add a resume link if you want recruiters to download your CV.

## Publish with GitHub Pages
1. Create a public GitHub repository named `yourusername.github.io` (replace `yourusername` with your GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After GitHub Pages finishes deploying, visit `https://yourusername.github.io`.

If you use a repository with another name, enable Pages in Settings and use the published URL GitHub shows you.
